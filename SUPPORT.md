# Support

Variaxiom is pre-alpha research software.

- Use **GitHub Discussions** for architecture questions, research ideas, and experiment design.
- Use **GitHub Issues** for reproducible defects and scoped feature proposals.
- Use the private route in `SECURITY.md` for vulnerabilities.
- Do not use security channels for general setup questions.

When asking for help, include the commit hash, operating system, Python/Rust versions, exact command, full error, and a minimal reproduction with secrets removed.
