# Variaxiom brand system

## Name

**Variaxiom** combines *variation* and *axiom*: the system may propose changes to almost every editable component, while promotions remain constrained by explicit, testable invariants.

Pronunciation: `vair-ee-AK-see-um` (English) / `вариа́ксиом` (Russian working pronunciation).

## Positioning line

> **Agents mutate. Evidence decides.**

Russian rendering:

> **Агенты мутируют. Доказательства решают.**

Do not dilute the line into generic claims such as “the autonomous agent that does everything.” The project is differentiated by proof-gated inheritance, not by maximal autonomy.

## Visual idea

The four outward paths represent variation. The protected central diamond represents an invariant. The central point represents an auditable decision anchored in evidence.

## Voice

Precise, ambitious, falsifiable, calm. Prefer “candidate,” “evidence,” “promotion,” and “lineage” over anthropomorphic claims. Public communication should distinguish demonstrated behavior from hypotheses and long-term research goals.
