# The Authority Test

This directory contains the deterministic public artifact generated by:

```bash
PYTHONPATH=src python3 scripts/regenerate_demo_docs.py
```

Files:

- [`authority-test.html`](authority-test.html) — human-readable decision report;
- [`demo-report.json`](demo-report.json) — structured result;
- [`lineage.jsonl`](lineage.jsonl) — append-only hash-chained event lineage.

The fixture compares two candidates built from the same tool implementation and evaluated by the same functional checks. The candidate requesting ungranted unrestricted network authority is rejected; the bounded candidate is promoted.

The checked-in result is documentation, not the source of truth for a local run. Recreate it and compare hashes whenever the demo implementation changes.
