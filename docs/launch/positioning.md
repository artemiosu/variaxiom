# Positioning

## Category

**Proof-gated agent evolution**

Alternative technical description:

**An evidence, lineage, and authority layer for agents that change themselves.**

## One sentence

Variaxiom turns agent-generated skills, tools, and harness edits into immutable candidates and promotes only descendants backed by independent evidence.

## Tagline

**Agents mutate. Evidence decides.**

Russian:

**Агенты мутируют. Доказательства решают.**

## The enemy

Not another vendor or framework. The enemy is the unexamined equation:

```text
self-editing = self-improvement
```

## The surprising truth

An agent can pass all functional tests and still be unfit for inheritance because it expands authority, overfits hidden assumptions, cannot be reproduced, or degrades future descendants.

## Audience-specific messages

### Agent builders

Stop copying “lessons learned” directly into prompts. Turn every change into a candidate with tests, lineage, scope, and rollback.

### Security engineers

Capability growth does not have to imply authority growth. Keep leases and promotion outside the model-editable loop.

### Researchers

Compare generations, not anecdotes. Preserve diverse lineages, held-out evidence, same-model controls, and full costs.

### OSS maintainers

Accept agent-generated contributions through evidence packages rather than raw code volume.

### Sponsors/investors

As self-updating agents proliferate, evaluation, lineage, policy, and rollback become infrastructure—not optional guardrails.

## Words to avoid in the main launch

- guaranteed singularity;
- unstoppable;
- autonomous life form;
- self-preserving;
- replaces all developers;
- fully safe;
- unhackable;
- AGI operating system.

These terms may appear in research discussions only with precise caveats.

## Narrative ladder

1. **Demo:** a candidate passes tests but is rejected for authority.
2. **Mechanism:** separate mutation, evaluation, selection, and authority.
3. **Architecture:** soma/germline, kernel/lab, lineage/archive.
4. **Research:** measure recursive improvement and metaproductivity.
5. **Vision:** a governed digital evolutionary ecosystem.
