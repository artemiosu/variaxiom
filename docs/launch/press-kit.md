# Variaxiom Press Kit

## Project

**Variaxiom**

## Tagline

**Agents mutate. Evidence decides.**

## 25-word description

Variaxiom is an open proof-gated substrate that evaluates, versions, and safely inherits agent-generated skills, tools, memory, and harness changes.

## 75-word description

AI agents can already write tools, save skills, and modify their workflows. But a self-edit is not automatically a self-improvement. Variaxiom turns every proposed change into an immutable candidate, evaluates it with independent evidence, checks authority and budgets, preserves lineage and rollback, and promotes only qualified descendants. The project is provider-neutral and begins with a runnable demo that rejects a functionally successful tool because it silently requests excessive authority.

## Founder quote

> “The question is no longer whether an agent can rewrite itself. The question is which changes deserve to become ancestors. Variaxiom makes that decision inspectable.” — Artem, `@artemiosu`

## Key facts

- Open-source, Apache-2.0.
- Seed date: September 2026.
- Python reference demo; Rust kernel scaffold; WIT/WASM component design.
- Provider-neutral: designed to wrap changes from multiple models and harnesses.
- Human-governed authority, protected evaluators, bounded reproduction, and rollback.
- Research status; no claim of guaranteed recursive self-improvement.

## FAQ

### Is it another coding agent?

No. It is an evidence, promotion, and lineage layer for changes produced by agents and harnesses.

### Does it let an AI freely rewrite itself?

No. Agents may propose candidates; protected evaluation and deterministic governance decide inheritance.

### Does it promise a technological singularity?

No. It defines experiments and metrics for bounded recursive improvement and makes failures visible.

### Is it production-ready?

No. The seed is pre-alpha research software and must not be given production credentials or unrestricted execution.
