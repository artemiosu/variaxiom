# Bootstrap Decisions

| Decision | Chosen | Rejected alternative | Reason |
|---|---|---|---|
| Public name | Variaxiom | Eidos-X, VERA | more distinctive; encodes variation + invariant |
| Category | proof-gated agent evolution | “digital life” / AGI agent | concrete, falsifiable, credible |
| Tagline | Agents mutate. Evidence decides. | self-improving agent | states mechanism rather than hype claim |
| Architecture | temporary phenotypes + protected lineage | one immortal self-rewriting process | supports independence, rollback, populations |
| Kernel | small deterministic Rust target | everything as peer plugin | preserves an external trust boundary |
| Research plane | Python | all-Rust | iteration speed and AI ecosystem |
| Generated tools | WIT/WASM preferred | raw host shell | explicit capabilities and portable contracts |
| Service topology | modular monolith first | microservices/Kubernetes | semantic clarity and low operations cost |
| Memory promotion | evidence-gated | automatic reflection-to-skill | prevents persistent hallucination/staleness |
| “Metabolism” | budget/value accounting | autonomous wallet/self-preservation | avoids terminal survival conflict |
| Launch | working authority-rejection demo | manifesto-only launch | proof is shareable and defensible |
