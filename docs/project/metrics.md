# Metrics

## North-star research metric

**Verified Evolutionary Productivity (VEP)**

```text
VEP = independently verified descendant frontier gain
      ------------------------------------------------
      compute + API spend + elapsed time + human work + coordination + risk reserve
```

No single formula is universal. The project publishes the exact vector and normalization used in every experiment.

## Technical metrics

- accepted candidate reproducibility rate;
- critical regression escape rate;
- evaluator exploit detection rate;
- rollback success and time-to-recovery;
- lineage verification success;
- authority-escalation rejection rate;
- clean-room phenotype equivalence;
- held-in versus held-out delta;
- cost per accepted capability;
- human interventions per experiment;
- archive behavioral diversity;
- metaproductivity across generations.

## Open-source health metrics

Stars are an awareness metric, not the goal.

Track:

- README → demo-run conversion;
- unique successful demo runs (opt-in telemetry only, or release downloads as proxy);
- weekly active experimenters;
- first issue → first merged PR conversion;
- contributor 30/90-day retention;
- median review time;
- share of work by non-founder contributors;
- number of independent reproductions;
- number of external harness adapters;
- number of cited/used evidence packages;
- sponsor concentration and runway.

## Founder reputation metrics

- invited technical conversations, podcasts, workshops, and reviews;
- citations and substantive references rather than mentions alone;
- maintainers/researchers who reproduce or critique results;
- high-quality inbound collaboration offers;
- published postmortems and experiments completed on schedule;
- trust indicators: clear corrections, disclosed limitations, security response.

## Anti-metrics

Do not optimize directly for:

- raw tool-call count;
- number of subagents;
- lines of generated code;
- token consumption;
- benchmark score without cost/holdout;
- stars acquired through giveaways or coordinated manipulation;
- engagement generated by exaggerated AGI claims.
