## Accepted boundary

M2.1 now provides deterministic, cross-runtime verification evidence and explicit non-authorizing
anchor-transition results. Every public M2.1 result fixes `authorizing` to `false`. The protocol
and kernel expose no signing/private-key API, ambient authority source, candidate activation, or
lineage append.

M2.2 must separately specify and review transactional SQLite lineage, exact-head compare-and-swap,
idempotency, crash recovery, and projections before any verified proposal can affect durable
germline state. Production key custody and a human security review remain future deployment gates.
