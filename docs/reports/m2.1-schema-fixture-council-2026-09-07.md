## Accepted boundary

The fixture oracle has no signing API, no ambient trust or time source, and no lineage-append
capability. The schema/fixture freeze authorizes the next implementation phase only: a disabled
Python/Rust verifier that must consume this frozen corpus without changing its semantics.

Before production enablement, Variaxiom still needs implementation review, production key-custody
and rotation procedures, an external human review when feasible, and M2.2 transactional
exact-head compare-and-swap before any signed result may append durable lineage.
