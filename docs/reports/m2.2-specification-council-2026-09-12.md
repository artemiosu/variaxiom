## Accepted boundary

M2.2 specifies a separately operator-authorized Rust writer, complete in-write M2.1 re-verification,
exact idempotency and head comparison, append-only rollback reservations, deterministic projections,
durable external-root intent/finalization, bounded recovery, and fail-closed control/integrity
latches. Results and readers remain non-authorizing, and root finalization precedes acknowledgement
or outbox handoff.

The next change may freeze only exact v3 schemas, SQL migration bytes and digest, a deterministic
Python oracle, and shared transaction/fault fixtures. Writer implementation remains disabled and
requires another three-role review before any durable lineage path can be enabled.
