# Research Agenda

## R1. Proof-carrying skills

Can a procedural skill package contain enough machine-checkable evidence, scope, and invalidation metadata to be safely reused across models and environments?

## R2. Causal harness repair

How accurately can traces be mapped from terminal verifier failures to the responsible editable component? Compare LLM attribution, causal interventions, and deterministic dependency tracking.

## R3. Soma-to-germline promotion

Which validation sequence best prevents transient session errors from becoming inherited memory without making learning economically impossible?

## R4. Evolutionary productivity

Develop metrics that reward an improver for producing strong future descendants, not merely for its current one-shot task score.

## R5. Diversity preservation

Compare novelty search, quality-diversity archives, behavior embeddings, lineage distance, and evaluator disagreement as defenses against population collapse.

## R6. Evaluator integrity

Create a public corpus of reward hacks and evaluator exploits for agent/harness evolution. Measure detection by deterministic, adversarial, and model-based evaluators.

## R7. Capability versus authority

Test whether systems can gain substantial tool-building and reasoning capability while keeping external authority constant. Quantify how much common benchmark performance actually depends on broad permissions.

## R8. Safe generated-tool interfaces

Evaluate WIT/WASM capability manifests against OCI sandboxes for portability, attack surface, latency, developer experience, and expressiveness.

## R9. Memory invalidation

Study TTL, contradiction graphs, environment fingerprints, active revalidation, and forgetting policies on long-lived agent reliability.

## R10. Multi-agent unit economics

Find when specialized cells outperform one agent under identical compute/token budgets. Measure duplication, coordination overhead, context transfer, and error propagation.

## R11. Model–harness attribution

Separate gains caused by model upgrades from gains caused by harness mutations using matched historical controls, local open models, and provider fingerprints.

## R12. Recursive improvement stage gates

Specify and test thresholds for moving from tool/skill generation to harness optimization, optimizer optimization, weight adaptation, and compute-system optimization.

## Initial benchmark program

1. Bootstrap promotion invariants.
2. Trace-grounded repair of a small coding harness.
3. Generated bounded tools in WASM.
4. Memory poisoning and revalidation challenge.
5. Population archive versus single-lineage overwrite.
6. Metaproductivity benchmark: which parent produces better descendants under fixed budget?
